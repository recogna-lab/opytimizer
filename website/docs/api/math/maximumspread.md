# `MaximumSpread`

**Module:** `opytimizer.math.metrics`

Maximum spread: diagonal of the bounding box of the obtained front.

MS = sqrt(sum_m (max f_m - min f_m)^2), as defined by Zitzler, Deb and
Thiele (2000).

## Constructor

```python
MaximumSpread()
```
