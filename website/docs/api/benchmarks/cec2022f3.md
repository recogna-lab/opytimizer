# `CEC2022F3`

**Module:** `opytimizer.benchmarks.cec2022`

CEC 2022 F3: shifted Schaffer's F7 function (f* = 600).

The report lists a rotated expanded Schaffer's f6; the official code evaluates
Schaffer's F7 on the shifted variables, before the rotation.

## Constructor

```python
CEC2022F3(n_variables: int = 10, env: Optional[opytimizer.core.environment.Environment] = None) -> None
```

### Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `n_variables` | `int` | `10` | Number of decision variables, one of the dimensions with official data (2, 10 or 20; 10 or 20 for F6-F8). |
| `env` | `Optional[opytimizer.core.environment.Environment]` | `None` | Environment that runs the problem. Defaults to numpy / float64. |
