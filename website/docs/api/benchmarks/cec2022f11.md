# `CEC2022F11`

**Module:** `opytimizer.benchmarks.cec2022`

CEC 2022 F11: composition function 3 (expanded Schaffer's f6, modified
Schwefel, Griewank, Rosenbrock, Rastrigin; f* = 2600).

## Constructor

```python
CEC2022F11(n_variables: int = 10, env: Optional[opytimizer.core.environment.Environment] = None) -> None
```

### Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `n_variables` | `int` | `10` | Number of decision variables, one of the dimensions with official data (2, 10 or 20; 10 or 20 for F6-F8). |
| `env` | `Optional[opytimizer.core.environment.Environment]` | `None` | Environment that runs the problem. Defaults to numpy / float64. |
