# `CEC2017F6`

**Module:** `opytimizer.benchmarks.cec2017`

CEC 2017 F6: shifted Schaffer's F7 function (F* = 600).

Function 5 of the final definitions document, which lists a rotated expanded
Schaffer's F6; the official code evaluates Schaffer's F7 on the shifted
variables, before the rotation.

## Constructor

```python
CEC2017F6(n_variables: int = 10, env: Optional[opytimizer.core.environment.Environment] = None) -> None
```

### Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `n_variables` | `int` | `10` | Number of decision variables, one of the dimensions with official data for this function (see the module docstring). |
| `env` | `Optional[opytimizer.core.environment.Environment]` | `None` | Environment that runs the problem. Defaults to numpy / float64. |
