# `CEC2022F12`

**Module:** `opytimizer.benchmarks.cec2022`

CEC 2022 F12: composition function 4 (HGBat, Rastrigin, modified Schwefel,
Bent Cigar, elliptic, expanded Schaffer's f6; f* = 2700).

## Constructor

```python
CEC2022F12(n_variables: int = 10, env: Optional[opytimizer.core.environment.Environment] = None) -> None
```

### Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `n_variables` | `int` | `10` | Number of decision variables, one of the dimensions with official data (2, 10 or 20; 10 or 20 for F6-F8). |
| `env` | `Optional[opytimizer.core.environment.Environment]` | `None` | Environment that runs the problem. Defaults to numpy / float64. |
