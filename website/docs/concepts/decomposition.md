# Decomposition and Reference Vectors

Decomposition-based algorithms, such as MOEA/D, transform a multi-objective problem into $N$ scalar subproblems. Each subproblem is defined by a weight (reference) vector $\lambda$ and an aggregation function.

## Aggregation Functions

The `opytimizer.math.aggregation` module provides the following scalarization functions, where $z^*$ is the ideal point:

* **`WeightedSum`**: $g(x \mid \lambda) = \sum_{i=1}^{M} \lambda_i f_i(x)$
* **`Tchebycheff`**: $g(x \mid \lambda, z^*) = \max_{1 \le i \le M} \lambda_i \lvert f_i(x) - z_i^* \rvert$
* **`PBI`**: $g(x \mid \lambda, z^*) = d_1 + \theta d_2$

In Penalty-based Boundary Intersection (PBI), $d_1$ is the distance of the projection of $F(x) - z^*$ onto $\lambda$, $d_2$ is the perpendicular distance to $\lambda$, and $\theta$ is a penalty parameter (default `5.0`).

## Reference Vectors

The `opytimizer.utils.reference_vectors` module generates uniformly distributed weight vectors over the unit simplex:

* **`das_dennis(n_objectives, n_partitions)`**: Das-Dennis method, which returns the weight matrix and the number of generated vectors.
* **`two_layered_weights_simplex(m, H1, H2)`**: Two-layered approach, which generates boundary and inner vectors for many-objective problems.

The number of vectors generated by the Das-Dennis method is:

* $N = \binom{H + M - 1}{M - 1}$

Where $H$ is the number of partitions and $M$ is the number of objectives. The number of vectors is usually used as the number of agents.

## Example Code

```python
from opytimizer.math.aggregation import PBI
from opytimizer.utils.reference_vectors import das_dennis

# Generates the weight vectors and the number of agents
weights, n_agents = das_dennis(n_objectives=3, n_partitions=12)

# Creates the aggregation function
pbi = PBI(theta=5.0)

print(weights.shape, n_agents)
```
